## 这个仓库里有什么

每个知识点一个目录，结构统一：

```
知识点名/
├── xxx.md      正文，图片用相对路径引用 figs/，在 GitHub 上直接渲染
├── xxx.pdf     排版后的版本，适合手机、平板阅读
└── figs/       正文里引用的图（SVG 矢量图 / PNG 位图）
```

图基本都是自己画或生成的。能画出来，说明真的想明白了；画不出来，说明还没想明白，得回去再读一遍。
