## 装配篇的差异

装配篇不写“原始设计 / 前沿演化”，改为：

1. 一句话结论 + 3 要点
2. 整机总图（照论文 Figure 1 布局）
3. 数据流：一个 token 从进到出的完整路径（每个模块只给一句话结论 + 指回链接）
4. 跨模块机制：mask 体系、交叉注意力、训练 vs 推理、KV cache 的使用方式
5. 三种拓扑（encoder-only / decoder-only / encoder-decoder）
6. 演化谱系图 + 小结表
7. 面试易错点
8. 引用论文

## 交付前问自己三句

1. 读者合上笔记，能不能说出每个模块**为什么要存在**（不只是它怎么算）？
2. 每个“为什么不用别的做法”都有回答吗（结构论证 / 数字 / 失效模式）？
3. 精髓句是不是换掉机制名就不成立了（否则仍是同义复述）？
